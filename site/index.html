Open-source culling for DNG shoots

Cull on focus.Fix the rest in the edit.

cull is a command-line tool that culls a shoot of DNG files before you import it into Capture One or Lightroom. A vision model assesses each frame’s full-resolution preview for focus, exposure and composition. Fixed rules in cull’s own code turn that into keep, review or cull.

60 Principle

What decides keep, review or cull.

  1. ICull

    Missed focus is culled.

    Focus is judged at the eyes, on a native-resolution crop of the full preview. Soft frames go to review.

  2. IICorrect

    Exposure gets fixed, not culled.

    The model suggests a correction in stops. Exposure alone never culls a frame; clipped highlights send it to review.

  3. IIICrop

    Composition gets cropped, never culled.

    A suggested crop is a note on a keeper, not a reason to cull it.

The model describes.
Fixed rules decide.

PreviewModel: describeRules: decide

The vision model (Claude) only reports what it sees: where focus should be, how sharp it is there, the exposure and the composition. Keep, review and cull are then decided by fixed rules in cull’s own code. The same description always gets the same verdict, every verdict comes with the reason for it, and you can tune the rules without paying to judge again.

250 Offload

Copy the card once, and check every file against it.

  1. Read the card once, hashing every file with SHA-256 as it is read.
  2. Write into a dated shoot folder.
  3. Drop the copy from memory and read it back from the disk to verify it.
  4. Flush the drive’s write cache.
  5. Print safe to format the card only when every file is verified.

500 Judge

Focus is checked at the eyes, at full resolution.

Every DNG carries a full-size JPEG preview made by the camera: 9504 × 6320 pixels on the M11-P. cull reads that preview instead of developing the raw file, and judges sharpness on a crop of it at 100%, at the eyes, not on a shrunken copy of the whole frame.

Face detection finds the subject. With no face, the model first picks out what was meant to be sharp. It’s also told which camera made the frame, so for a Leica M it expects manual focus and fast lenses shot wide open.

Sets

Bursts are compared side by side.

Near-identical frames, such as a burst, form a set, and the model ranks each set by looking at its frames together. The best three keep their verdicts; the rest go to review, or straight to cull if you choose.

Junk filter

Blank frames are set aside for free.

Lens-cap shots, blown-white frames and other blanks are caught by simple brightness checks on your Mac, before any model sees them, so they cost nothing to judge.

Calibrate

Measure its accuracy on your own photos.

Label a sample of frames. cull calibrate then reports how often cull culled a frame you’d keep, and what each combination of policy settings would change.

Don’t act on its culls until you’ve checked it this way. Tuning is one command and calls no model: you pick a row from the grid and apply it. How to tune.

After import

apply-c1 pushes changes made after import into Capture One by AppleScript. By default it only prints the script.

Your DNGs are never modified. Every move is recorded, and cull restore undoes it.

Copy speeds: an M11-P card in a USB card reader, timed until each tool’s data was actually on the disk. Ordinary copies report “done” before the disk has finished writing, and check nothing; cull reads every copy back from the disk and compares it with the card’s fingerprint. On both drives the checked copy finished as fast as or faster than the unchecked ones. Finder itself wasn’t timed; ditto uses the same system copy routines. Over a slow network the check costs more: to a NAS over Wi-Fi, copy to your Mac first. Culling figures: a 979-frame shoot labelled by hand and compared with cull’s verdicts. About half the frames needed no 100% check; choosing moments among the keeps is still yours. Your results depend on how you shoot; cull calibrate measures them on your own photos. 4000 Install

Install cull.

One universal binary for Apple silicon and Intel Macs. Open source, written in Go: every rule that keeps or culls a frame is in the repository.

$ brew install jefflaplante/tap/cull

Or download the binary from the latest release:

$ curl -fsSL https://github.com/jefflaplante/cull/releases/latest/download/cull_macos_universal.tar.gz | tar -xz && sudo mv cull_macos_universal/cull /usr/local/bin/

Or build from source with Go 1.26:

$ git clone https://github.com/jefflaplante/cull && cd cull && make build

Releases are built for macOS. Each one lists its SHA-256 checksum.

Flags you always type can go in ~/.cull as your own defaults: how, and which value wins.
