# Part 3: Junk Pre-filter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** frames that are unmistakably empty (black, blown white, uniform) are flagged
during preparation and decided by policy, with no model call. Plus a small fix carried
over from Part 2: `--verify` must ignore AppleDouble `._` files.

**Architecture:**
- **`imageprep.Stats` gains `DarkPct`, `BrightPct` and `Contrast`.** Contrast is the luma
  std of a 64 px thumbnail. `imageprep.Junk(Stats)` classifies a frame with the measured
  thresholds.
- **`report.Result` gains `Junk *JunkInfo`,** filled by `prepareFrame`.
- **`processOne` returns early** for a junk frame, unless the policy action is `ignore`.
- **`eval.Policy` gains `Junk Action`.** `decideAll` decides junk frames by that action,
  outside sets.
- **The CLI adds `--junk`;** scan prints a junk count, and calibrate includes junk frames.

**Tech Stack:** Go stdlib; no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-02-preingest-workflow-design.md`, Part 3. It was
rewritten 2026-10-02 from the 992-frame measurements.

## Global Constraints

- **Thresholds** (constants in imageprep, values recorded in the report): black is
  `DarkPct ≥ 98` (luma < 16); white is `BrightPct ≥ 95` (luma ≥ 250); uniform is
  `Contrast < 3`. When several apply, black and white win over uniform.
- **They must flag none of the 17 samples, and exactly M1103546 among the 992 frames on
  Grey.** The Grey check is read-only, with `scan -o` writing the report to `$TMPDIR`.
  Nothing is written to `/Volumes/Grey`, and nothing on Grey or the card is deleted.
- **The policy default is `cull`** (flag default). A stored policy without the field
  decides junk as review, the zero value: `Action`'s documented conservative default.
- **Old reports** have no `Junk`, so nothing changes for them.
- **Labels override,** via `labels.Effective`, unchanged.
- **Running Go:** `GOCACHE=$TMPDIR/gocache`, with the cli tests unsandboxed.
- Branch `feat/junk`.

## Review Focus

- **A real low-key portrait is never junk:** a synthetic dark-background portrait whose
  thumbnail std sits around 10 isn't flagged. *Task 2:
  `TestJunkClassify/low-key portrait`.*
- **A frame just under each threshold is flagged, and one just over isn't.** *Task 2:
  boundary cases.*
- **`--junk ignore` really sends the frame to the model.** *Task 3:
  `TestJunkIgnoreJudges`.*
- **A resumed judge doesn't re-process or drop junk frames.** *Task 3:
  `TestResumeKeepsJunk`.*
- **Junk frames never join a set,** where they would take a set's "best" slot. *Task 3:
  `TestJunkOutsideSets`.*

**Interfaces (Produces):**

```go
// imageprep
type Stats struct { /* existing */ DarkPct, BrightPct, Contrast float64 } // json dark_pct, bright_pct, contrast
const (JunkDarkPct = 98.0; JunkBrightPct = 95.0; JunkContrast = 3.0)
func Junk(s Stats) string // "black" | "white" | "uniform" | ""

// report
type JunkInfo struct {
	Kind      string  `json:"kind"`
	DarkPct   float64 `json:"dark_pct"`
	BrightPct float64 `json:"bright_pct"`
	Contrast  float64 `json:"contrast"`
}
// Result.Junk *JunkInfo `json:"junk,omitempty"`
```

**How it's measured:**
- `DarkPct` and `BrightPct` are over `Frame.Luma` (display luma, every pixel).
- `Contrast` is the std of `DownLuma(Luma, W, H, 64)`.
- All three are rounded to 2 decimals for the report.

### Task 3: Policy, pipeline and CLI

**Files:** `internal/eval/types.go` (`Policy.Junk`, `DecideJunk`), `internal/pipeline/
pipeline.go` (processOne early return; resume keeps junk), `groups.go` (`decideAll`),
`internal/cli/policy.go` (`--junk`), `internal/cli/summary.go` (ScanSummary junk count),
`internal/calib/calib.go` (include junk; list junk you labelled keep), tests in each
package, README (policy flags and a "Junk frames" paragraph).

**Interfaces (Produces):**

```go
// eval
// Policy.Junk Action `json:"junk"`
// DecideJunk decides a frame flagged junk: (decision, reasons, true), or ok=false
// when the action is ignore (judge it normally).
func (p Policy) DecideJunk(kind string, detail string) (Decision, []string, bool)
```

**Rules:**
- **`processOne`:** after `prepareFrame`, if `res.Junk != nil` and
  `cfg.Policy.Junk != ActionIgnore`, return the result with no face detection, locate or
  evaluate. A verbose note says so.
- **Resume (`startRun`):** keep previous results with `Junk != nil`, when the action isn't
  ignore, as done.
- **`decideAll`:**
  - a result with `Junk` and no Evaluation is decided by `DecideJunk`;
  - when `DecideJunk` says ignore and there's no Evaluation, the decision stays `""`;
  - junk results are skipped when building sequence frames.
- **Reason text:** `"junk: white (99.95% of pixels blown)"`, `"junk: black (99.1% of
  pixels near-black)"`, `"junk: uniform (thumbnail contrast 0.3)"`.
- **CLI:** `--junk` (default `cull`) on judge and decide, through the shared policy
  flags, and stored and resolved like `--eyes-closed`.
- **ScanSummary** appends `; junk: N (white 1, ...)` when N > 0.
- **calibrate:** `compare` includes results with `Junk` and a Decision even without an
  Evaluation. `Format` adds `junk filter: K of N junk frames you labelled keep: <names>`
  when there are junk frames with labels.
