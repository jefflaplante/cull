Open-source culling for DNG shoots

Cull on focus.Fix the rest in the edit.

cull is a command-line tool that culls a shoot of DNG files before you import it into Capture One or Lightroom. A vision model assesses each frame’s full-resolution preview for focus, exposure and composition. Fixed rules in Go turn that into keep, review or cull.

60 Principle

Three priorities, in order.

  1. ICull

    Missed focus is culled.

    Focus is judged at the eyes, on a native-resolution crop of the full preview. Soft frames go to review.

  2. IICorrect

    Exposure gets fixed, not culled.

    The model suggests a correction in stops. Exposure alone never culls a frame; clipped highlights send it to review.

  3. IIICrop

    Composition gets cropped, never culled.

    A suggested crop is a note on a keeper, not a reason to cull it.

The model assesses.
Go decides.

PreviewModel: assessGo: decide

The vision model (Claude) only reports what it sees: where focus should be, how sharp it is there, the exposure, the composition. Keep, review and cull are decided by deterministic rules in Go. The same assessment always gets the same decision, and you can read the rule that made it.

250 Offload

Read the card once. Verify every file.

  1. Read the card once, hashing every file with SHA-256 as it is read.
  2. Write into a dated shoot folder.
  3. Drop the copy from memory and read it back from the disk to verify it.
  4. Flush the drive’s write cache.
  5. Print safe to format the card only when every file is verified.

500 Judge

Judged at the eyes, at full resolution.

cull reads the embedded JPEG preview inside each DNG: 9504 × 6320 on the M11-P. Sharpness is judged on a native-resolution crop at the eyes, not on a downscaled frame.

Face detection finds the subject. Without a face, the model first locates what was meant to be sharp. The prompt names the camera, so for a Leica M it expects manual focus and fast lenses shot wide open.

Sets

Best of a burst, side by side.

Frames with near-identical framing, such as a burst, form a set, and the model ranks each set side by side. The best three keep their verdicts; the rest go to review.

Junk filter

Blank frames cost nothing.

Lens-cap, blown-white and blank frames are set aside without a model call.

Tested on 992 real frames: every real frame cleared the thresholds by a wide margin, and the one blank frame was caught.

Calibrate

Calibrate before you trust it.

Label a sample of frames. cull calibrate then reports how often cull culled a frame you’d keep, and what each threshold would change.

Nothing should auto-apply until it’s calibrated. The rules are code, so tuning them means moving a threshold, not rewording a prompt.

After import

apply-c1 pushes changes made after import into Capture One by AppleScript. By default it only prints the script.

Your DNGs are never modified. Every move is recorded, and cull restore undoes it.

4000 Install

Install cull.

One universal binary for Apple silicon and Intel Macs. Open source, written in Go: every rule that keeps or culls a frame is in the repository.

$ brew install jefflaplante/tap/cull

Or download the binary from the latest release:

$ curl -fsSL https://github.com/jefflaplante/cull/releases/latest/download/cull_macos_universal.tar.gz | tar -xz && sudo mv cull_macos_universal/cull /usr/local/bin/

Or build from source with Go 1.26:

$ git clone https://github.com/jefflaplante/cull && cd cull && make build

Releases are built for macOS. Each one lists its SHA-256 checksum.

Flags you always type can go in ~/.cull as your own defaults: how, and which value wins.
